# Data

Two data sources are supported. Both use **identical file names and layout**, so every script only needs
`--data_dir` to switch between them.

| Folder | Content | In git? |
| :--- | :--- | :--- |
| `data/dummy/BRCA/` | **Synthetic** TCGA-BRCA-like data (no real patients) generated by `make_dummy_data.py` | yes |
| `data/BRCA/` | Real UCSC Xena TCGA-BRCA files, fetched by `download_xena_data.py` | **no** (git-ignored) |

## Expected files (UCSC Xena format)

| File | Description |
| :--- | :--- |
| `TCGA.BRCA.sampleMap_HiSeqV2` | mRNA, gene-level log2(normalized count + 1), Illumina HiSeq |
| `TCGA.BRCA.sampleMap_HumanMethylation450` | DNA methylation beta values (0-1), Illumina 450K |
| `TCGA.BRCA.sampleMap_miRNA_HiSeq_gene` | miRNA expression, log2(RPM + 1), Illumina HiSeq |
| `TCGA.BRCA.sampleMap_Gistic2_CopyNumber_Gistic2_all_data_by_genes` | gene-level CNV, GISTIC2 scores |
| `survival_BRCA_survival.txt` | clinical survival: columns `sample`, `OS` (event), `_PATIENT`, `OS.time` (days) |

Omic files are tab-separated, **rows = features, columns = sample barcodes**, first header cell `sample`.
Each omic is used as an independent single-omic cohort; samples are matched to the survival table by barcode.

## Synthetic data

```bash
python data/make_dummy_data.py                 # writes data/dummy/BRCA  (600 patients, seed 0)
python data/make_dummy_data.py --n_patients 1000 --seed 1 --out_dir data/dummy/BRCA_large
```

The generator mimics the *format* and the strong STS / LTS / censored imbalance of TCGA-BRCA, covers each omic
with a different random subset of patients (low cross-modality overlap), injects missing values and
near-constant features (to exercise the filters), and plants a weak survival-related signal so that the models
have something to learn.

## Real data

```bash
python data/download_xena_data.py            
python run_cmvae.py --omic mRNA --data_dir data/BRCA
```
